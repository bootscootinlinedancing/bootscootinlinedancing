# Version 90.2 — Ranch Operations & Stability

## Ranch/HQ fixes
- Removed the duplicate inline health script that conflicted with ranch.js.
- Replaced multiple competing health loaders with one ten-second, fail-safe controller.
- System Health now shows ready, information, setup or error states consistently.
- HQ Access and launch-checklist colours update from the same live result.
- Removed the old timer that changed loading text without verifying services.
- Added customer-friendly backend errors and visible success/error toast messages.
- Added Customers to the HQ sidebar.

## Phase 4 operations
- Added a Daily Operations Centre.
- Today’s class and guest totals.
- Paid revenue and pending-payment totals.
- Waiting-list and refund-review totals.
- Action queue for pending payments, refunds/credits and waiting-list entries.
- Recent audit activity feed.
- Today/next-class register.
- Printable operations register.

## Waiting-list administration
- Promote a waiting-list entry into a manual booking when capacity is available.
- Remove a waiting-list entry.
- Capacity validation before promotion.
- Audit records for both actions.

## Dashboard
- Stable overview card IDs.
- Paid revenue now comes from real booking data rather than estimated class capacity.
- Recent activity is driven by the audit log.
- Operations and overview refresh together.

All V90.1 booking, customer, class, media, private-event and security foundations remain included.
