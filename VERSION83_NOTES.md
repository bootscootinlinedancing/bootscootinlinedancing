# Version 83 — Live Class Manager

## HQ class management
- Create and edit classes directly in Boot Scootin’ HQ.
- Publish live, save as draft, close or cancel a class.
- Reopen cancelled or closed classes.
- Duplicate any class one week later as a draft.
- Save a class and immediately prepare its next duplicate.
- Delete only classes with no bookings or waiting-list records.
- Prevent capacity being reduced below the number of booked places.

## Venue defaults
- Edgbaston Community Centre: capacity 20.
- Low Places: capacity 50.
- Venue location and capacity fill automatically and remain editable.
- Finish time defaults to one hour after the start time.

## Class information
- One standard “Before You Arrive” message is used for every class.
- Each class has only one optional additional-note field.
- Draft/live/closed/cancelled state is explained clearly before saving.

## HQ overview
- Live class, draft, booked-place and waiting-list totals.
- Each row shows sold capacity, remaining spaces and waiting-list quantity.

## Safety
- Payments remain disabled until SumUp is connected.
- Customer data remains protected by the existing HQ access safeguards.
