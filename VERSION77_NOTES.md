# Version 77 — The Boot Scootin' Trail

## Added
- Rebuilt the Passport page as **The Boot Scootin' Trail**.
- Trail ranks from First Steps to Hall of Fame.
- Boot Points earning rules and a reward catalogue.
- Achievements, seasonal challenges and memory stamps.
- Privacy-first, opt-in "Who's Going?" preview.
- D1 tables for member profiles, points ledger, achievements and rewards.
- Trail & Rewards preview inside Boot Scootin' HQ.
- Standard "Before You Arrive" information on the booking page.
- Branded Dance Pass preview on the booking confirmation page.

## Safety
- Member points remain inactive until secure member authentication launches.
- No public leaderboard.
- Members cannot change their own point balance.
- Reward redemptions and point changes are designed to be auditable.
- "Who's Going?" is opt-in and never exposes contact details.
